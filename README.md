# 💖 AI Relationship Simulator

An AI-powered relationship simulator that creates dynamic virtual personalities capable of holding realistic conversations, adapting their mood, and building relationships over time.

Built using **Next.js**, **FastAPI**, **Supabase**, and **Groq**, the project aims to simulate emotionally engaging conversations through persistent memory, personality traits, mood changes, and contextual responses. Future versions will integrate Machine Learning to create even more adaptive and personalized AI behaviour.

---

## ✨ Features

### 💬 Intelligent Conversations

* AI-powered conversations using Google Gemini.
* Context-aware responses.
* Persistent chat history.

### 😊 Dynamic Personality System

* Multiple AI personalities.
* Mood changes based on conversations.
* Time-aware behaviour (day/night interactions).
* Relationship progression with the user.

### ❤️ Relationship System

* Friendship/relationship meter.
* Responses evolve as the relationship develops.
* Personality-driven interactions.

### 👤 User Management

* Secure authentication.
* User profiles.
* Conversation history stored in Supabase.

### ⚡ Modern Architecture

* Next.js frontend.
* FastAPI backend.
* REST API.
* Supabase database.
